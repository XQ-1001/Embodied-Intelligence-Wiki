Microsoft — 具身智能布局

Microsoft Corporation（纳斯达克：MSFT）· 云平台 + 基础模型 + 战略投资

1 具身智能战略定位

Microsoft 在具身智能领域采取"云平台 + 基础模型 + 战略投资"三线并行策略：Azure 作为具身 AI 训练和推理的云基础设施、Microsoft Research 直接研发机器人基础模型（Rho-alpha）、通过投资 Figure AI 等头部公司间接进入人形赛道[1][2]。

与 NVIDIA 的"芯片+模型"全栈路线不同，Microsoft 的核心资产是Azure 云平台和 OpenAI 生态关系。Microsoft 通过 Azure IoT Operations、Fabric Real-Time Intelligence 等服务将具身 AI 从云端延伸到边缘设备，与 NVIDIA 在 Physical AI 工具链上深度合作而非竞争[3]。

Rho-alpha 是 Microsoft Research 的旗舰机器人模型，基于 Phi 系列。其核心创新在于将视觉、语言、动作与触觉传感融合（VLA+），训练数据来自物理演示、NVIDIA Isaac Sim on Azure 合成数据以及互联网视觉数据。模型支持通过 3D 鼠标进行人类遥操作纠错，实现持续学习[2]。

7 行业影响力评估

Microsoft 的具身智能影响力主要通过Azure 基础设施和投资杠杆实现。Rho-alpha 模型展示了 Microsoft 在机器人基础模型上的研发深度，但与 Google Gemini Robotics 和 NVIDIA GR00T 相比规模较小[2]。Azure 作为全球第二大云平台为机器人公司提供训练和部署基础设施，与 NVIDIA 的硬件生态形成互补[3]。

8 分析层

优势

  • Azure 云平台为机器人训练和部署提供基础
  • 通过投资 Figure AI 间接进入人形赛道
  • Rho-alpha × Isaac Sim on Azure 工具链有差异化

挑战/风险

  • 缺乏自有机器人硬件或深度绑定的人形合作伙伴
  • Figure AI 转向自研 Helix 模型后与 Microsoft/OpenAI 的关系可能疏远
  • 在具身基础模型竞赛中落后于 Google Gemini Robotics 和 NVIDIA GR00T
