Executive Summary

六个判断：Astra 之后，具身模型的钱该押在哪一层

本页是全篇结论。后续每一页都在为这六条提供证据链。

① 冲击落在"认知层"，不是"执行层"。
GPT-6 Astra 把具身智能的系统 2（理解环境、拆解任务、纠错重规划）变成了通用大模型的公共品——它并不直接控制关节，而是"想"。这正是过去三年被当作具身护城河的那一层。置信度 高
② 价值向两端迁移：端侧高频物理执行 + 场景暗数据。
Astra 的硬伤是成本（按 token 计费）、时延（秒级）、精度（米级）。50Hz 控制环、力/触觉接触、现场磨出来的暗数据——这三样通用基座打不到，成为新的护城河候选。置信度 高
③ 旧分类（按架构分）失效，新分类按"护城河建在哪一层"。
v1.0 的六维度（架构/数据/范式/本体/自研深度/场景）在 Astra 之后不再是区分变量的主轴。v2.0 提出四类新路线：认知外借、小脑自研、双基模闭环、统一一条式。置信度 中高
④ RoboDojo 取代"自主发布 Demo"成为新标尺，且中国模型已反超 Astra。
统一体、统一协议的"具身高考"上，星动纪元 VPP2（14B、无额外数据、开源）以 39.26 分登顶，把 Astra 的 28.97 分、π0.5 的 14.67 分甩开；原力灵机 DM0.5 记忆维度断层第一。置信度 中高
⑤ "VLA vs 世界模型"之争基本结束，收敛为"分层 + 融合"。
宇树的命名史 WMA→VLA→WLA、智元 GO-3（WRAM）、Figure Helix 2.5——2026 年 9 月 8 天 5 款模型，落点一致：世界模型并进 VLA / 认知与执行解耦协同。竞争重心从架构转向数据与量产。置信度 高
⑥ 对创业者：窗口期 1–2 年；对投资人：重估"模型期权"。
纯认知层公司的估值溢价面临重定价；护城河可验证的（端侧物理基模、独占场景数据、有利润锚的整机）相对受益。定价最贵的恰是"只有认知叙事"的标的。置信度 中

The Event

事件：一个"不为机器人而生"的模型，接管了机器人的大脑

2026 年 9 月初，OpenAI 发布 GPT-6 Astra。随后几周，三组来自不同机构、不同本体的实机证据把它从"演示"推到了"行业冲击"的级别。

证据一 · RoboCurve 实机
95%
双臂机械臂"抓方块放入碗中"成功率。同任务 Claude Fable 5.1 仅 40%。零额外训练、直接输出夹爪位姿。
证据二 · Stanford/Caltech HomeBody
换厨房不重训
GPT-6 Astra 驱动宇树 G1 进陌生厨房：探索建图→收拾物品→把不在视野里的药找出来递给用户。
证据三 · 银河通用 RoboDojo 亲测
28.97 分
50 分制具身高考，Astra 以 22.48% 成功率断档式登顶，把当时主流具身模型甩开一倍以上。

为什么这三组证据比"又一个更强的 VLA"严重得多

① 它是跨界降维，不是同赛道升级。过去每发一代大模型，具身团队接进本体试一下都"不过尔尔"——因为通用模型的输出是"视网膜级"的语言/图像，落不到动作。这一次，Astra 在从未见过机器人数据的前提下，完成了"看懂环境→做决策→调度动作"的完整链路，跨环境、靠上下文自我纠错。[1][2]

② 它的短板恰好圈定了"打不到的地方"。把三段实机数据摆在一起，Astra 的三道坎清晰可见——成本（控制真车跑 134.7 米烧掉约 660 万 token、约 $7.74）、时延（反应周期以秒计，均速仅 0.42 m/s）、精度（导航以米级 2D 目标点为基准，做不了厘米级高精接触）。这三道坎，正是量产具身必须跨过的坎。[3]

③ 它把"要不要自研大脑"从信念问题变成了经济学问题。当一个免费/低边际成本、且持续升级的通用基座能干"想"的活，继续自研同等认知层的 ROI 急剧恶化——除非你能证明你的认知层相对通用基座有可守住的超额能力。

Capability Boundary

边界：Astra 强在"认得出、走得对"，弱在"摸得准"

破壳机器人创始人许华哲在 Astra 可用当天做了测试，把具身任务拆成三个维度。这个拆分比"能不能抓"更有解释力——它直接指出通用基座打不到的地方在哪。

三维泛化：Astra 的水位

语义泛化强
空间泛化较强
物理泛化弱

条形为定性示意（强/较强/弱），非定量基准分。依据许华哲在外滩大会的公开表述。[2]

一句话说清能做与不能做

能：认出桌面上的物体、走到正确位置、完成抓取；连筷子这类细小物体，也能拿起、旋转、递送——"它认识桌面上的东西，也会往正确的位置走"。

不能：用筷子拨动物体、堆叠盒子、折叠衣服等涉及复杂物理接触的任务。它不等于真正理解物体如何受力、如何变化。

"复杂物理交互仍是具身智能公司的最后阵地。"——许华哲

把短板翻译成工程语言：三道坎都是量产落地的前置条件

维度Astra 实测表现为什么通用基座短期跨不过去
成本控制真车跑完 134.7 米封闭道路，单次约 660 万 token ≈ $7.74，单公里大几十美元动作是连续、稠密的，按 token 计费的云端推理在量产成本结构里算不过来
时延平均车速 0.42 m/s，反应周期以秒计；技能切换之间会停顿物理世界需要 50Hz 以上的控制频率（每 20ms 一次反馈），云端往返做不到
精度导航以地图坐标的米级 2D 目标点为基准；高精度接触、稳定抓取成功率断崖下降米级意味着只知"大概到哪"，做不了厘米级高精接触与稳定抓取
关键推论：Astra 抬高的只是"大脑"。云端大脑相对端侧具身模型，在实时性、成本、物理空间精细感知与操作上全面落后——因此"云端通用基座直接当机器人大脑"不会成为量产主流，但它会重组整个模型栈的分工。

Anatomy of the Shock

本质：被商品化的不是"模型"，是整个认知层

把具身模型栈自上而下拆成五层，Astra 只精准击中了最上面那一层——但那一层恰好是过去三年一级市场定价的主要依据。

五层模型栈与 Astra 冲击方向示意。Astra 商品化 L4，迫使 L1/L0 的权重上升。

冲击为什么"大"

过去三年，一级市场的"模型期权"溢价主要买的是 L4 的想象空间。当 L4 变成人人可调用的公共品，这部分溢价失去支撑——这正是创业者口中"现在具身智能没有什么真正的护城河"的由来。

但它没有宣告具身终结

Astra 抬高的只是大脑。L1 的高频控制、L0 的暗数据天然不可被云端替代，且需要"一天天站在现场"才能积累。冲击是结构性的重定价，不是清零。

Why v1.0 Fails

旧框架为何失效：v1.0 的六维度，已不再是区分变量的主轴

v1.0（2026-06-11）用"架构 / 数据 / 训练范式 / 本体 / 自研深度 / 场景"六维度拆解公司，并给出结论"世界模型+VLA+RL 三件套融合"。三个月后，这个框架仍然正确地描述了技术现状，却不再能区分赢家与输家。

v1.0 维度Astra 之后的现实判别力变化
① 架构路线
端到端 / 分层 / 世界模型		架构正在趋同：8 天 5 款模型落点一致（世界模型并进 VLA / 认知与执行解耦），"VLA 降级为器官"。↓ 大幅下降 大家都往一个方向收敛
② 数据策略反而更重要——竞争重心从"架构之争"转向"数据战争"（暗数据 vs 公开数据）。↑ 上升 但需换口径：看独占性而非绝对量
③ 训练范式预训练-后训练分工已成常识；"自回归是否收敛方向"成为新焦点（智元/诺因/智谱）。→ 中性 从"差异点"变"及格线"
④ 本体策略与 Astra 冲击解耦，仍影响单位经济性（轮式 vs 双足）。→ 中性
⑤ 自研深度被 Astra 直接改写：自研"认知层"的溢价被压缩，货币从"自研多深"变成"哪一层自研"。核心变量⚠ 语义已变 需按层重估
⑥ 场景与数据飞轮上升为第一性问题：场景暗数据是 Astra 唯一买不到、爬不到的东西。↑ 大幅上升
结论：v1.0 回答的是"这家公司的技术栈长什么样"；Astra 之后投资人真正要回答的是"这家公司的超额能力建在哪一层、能守多久、会不会被通用基座或开源吃掉"。分类标准需要从"技术路线"迁移到"护城河路线"。

来源：WAIC 2026 观察（观察者网/凤凰网）[10] · OFweek（8 天 5 模型）[11] · 机器人大讲堂[1]

New Taxonomy

新路线分类：按"护城河建在哪一层"重画具身模型版图

Astra 之后，判别一家公司的模型路线不再问"架构怎么搭"，而问两个问题：认知层（大脑）从哪来？ · 物理执行层（身体）做到多深？ 由此得到四类新路线。

路线 A · 认知外借型

Borrowed Brain + Skill Library

认知：外借 GPT / Claude / Qwen 等通用基座。执行：传统技能库 + 经典控制（MPC / 视觉伺服 / 预训练控制策略）。

代表：Stanford/Caltech HomeBody（GPT 当 System2 直接调技能库、跳过学习型 VLA）；波士顿动力 × Gemini Robotics。

逻辑：承认大脑是公共品，资源全押本体、场景与技能工程——成本最低、随模型升级直接获益。

风险：认知命脉握在别人手里；技能库泛化靠人工堆；被通用基座厂商"顺手吞掉"。

路线 B · 小脑自研型

Own the Cerebellum

认知：可外借也可自研。执行：自研端侧高频物理执行基模——运控 / 力控 / 触觉，即"小脑 GPT"。

代表：银河通用 AstraBrain-WBC 0.5（8040 万参数·20 亿帧·0.39ms·50Hz）；千寻智能力控；帕西尼触觉；星动纪元 VPP2 的 WAM。

逻辑：端侧算力与频率的硬约束使"小脑"不可被云端替代——这是 Astra 结构上打不到的层。

风险：运控/力控/触觉数据采集成本高；脱离认知层难单独变现，易沦为"部件供应商"。

路线 C · 双基模闭环型

GPT × WAM（认知与执行解耦协同）

认知：自研或协同通用基座。执行：自研世界-动作模型（WAM），形成"预测—行动—反馈"闭环。

代表：星动纪元 VPP2 + GPT（论文实测：加 GPT 规划器，5 任务成功率 27.6%→57.6%）；智元 GO-3（WRAM）；诺因 GLOW。

逻辑：认知与物理执行各自规模化、再闭环协同——"通用认知 × 通用物理执行"。星动自述为该范式首提者。

风险：两套基模算力与数据双高；工程整合复杂；一旦通用基座直接吃下"做"，中间层被夹击。

路线 D · 统一一条式型

Unified / One Model

认知 + 执行：单一端到端模型同时扛理解与动作。

代表：它石智航 AWE 3.0（"不 VLA、不仿真、不遥操"）；自变量 WALL-A / 世界统一模型；Skild Brain。

逻辑：赌端到端上限，避免分层链路的级联误差放大。

风险：在 Astra 冲击下最承压——认知部分被通用基座降维，物理部分又不聚焦端侧高频，两头不靠。

四条路线并非互斥。真实公司往往是"主路线 + 副路线"（如智元 = C + B，宇树 = A 起步转向 C）。分类的价值在于判断它的估值溢价到底押在哪一层、那一层是否可守。另注：横跨四条路线之上的数据/场景层（L0）不是"路线"而是底座，决定前四者的持久性。

来源：本报告综合。路线 C 的代表性证据见星动纪元 VPP2 论文[4][6]；银河通用小脑 GPT 见[7]；路线之争分野见 WAIC 2026 观察[10]。

China's Answer · I

中国模型的回应（一）：14B 开源模型登顶，物理执行层不是"降维"能拿下的

Astra 登顶 RoboDojo 后不到一个月，榜首换成了中国名字。这两个案例恰好分别对应"路线 C（双基模闭环）"和"路线 B（小脑/执行深耕）"。

路线 C · 双基模闭环

星动纪元 VPP2（Video Prediction Policy 2）

成绩：RoboDojo 平均成功率 32.26%、平均得分 39.26，登顶；同时拿下泛化、精度、记忆三项单项第一，超越 GPT-6 Astra（22.48%/28.97）。

三大细节：① 仅 14B 参数；② 未用任何额外数据、未用 agent RSI——按官方 baseline 协议"裸考"；③ 开源可复现。没有场外信息辅助，成绩不可能是过拟合堆出来的，证明的是预训练沉淀的原生能力（即泛化性）。

技术核心＝"解耦 + 排序"：视频预测的质量决定动作的上限，两者必须拆开——先"脑内"预演物理变化，再输出动作。管线四步：事件级视频预训练 → 语言条件化视频预测 → 基于视频模型 KV cache 训动作专家 → 专项后训练。0.2 秒推理输出 0.8 秒动作块。

GPT+WAM 的实证：给 VPP2 加一个 GPT 类"子任务规划器"，5 个任务平均成功率从 27.6% 跳到 57.6%，井字棋类任务 0→38 分。GPT 管"想"，WAM 管"做"。

路线 B · 执行深耕（记忆维度）

原力灵机 DM0.5（重庆两江新区）

Value Re-Rating

被忽略的物理约束：为什么"云端大脑"注定只能干低频的活

价值迁移不是叙事选择，而是算力与带宽的硬约束决定的。云端可以跑万亿参数但延迟以秒计；端侧实时但只能跑几十亿参数。这道"蒸馏鸿沟"划定了通用基座的上限。

本图为工程约束示意，非某一公司架构图。

唯一模型外的变量：通用基座厂商亲自下场

OpenAI 于 2026 年年中重启硬件自研（Aditya Ramesh 领导，Altman 公开确认人形方向）。这意味着"Astra 只做大脑"可能只是阶段策略——一旦基座厂商同时做本体，纯认知层与纯本体两端都被挤压，"端侧执行 + 独占数据"的中间层价值反而更稳。[14]

三点尽调提示：① 自研认知层的"超额能力"若无法在统一榜单上与通用基座拉开可复现差距，其估值溢价缺乏支撑；② "模型期权"占估值 60–80% 的标的（v1.0 口径）在重估中最脆弱；③ 只有"有利润/有订单/有独家数据"的标的具备下行保护。

Bottom Line

核心判断：Astra 不是终点，是把行业打回"该挣的钱"

以下为报告作者判断，非事实陈述；每条附置信度与主要不确定来源。

① 认知层不再值得单独押注。
除非能证明"相对通用基座有可复现、可守 18 个月以上的超额能力"，否则继续自研同等认知层的 ROI 急剧恶化。不确定来源：通用基座是否持续开源/降价的商业策略。置信度 高
② 护城河在两个地方：端侧物理基模，和现场暗数据。
前者受"蒸馏鸿沟 + 高频控制环"保护，后者受"独占性 + 时间"保护。二者共同点是通用基座在成本与物理上都进不来。置信度 高
③ 新分类不是"更强 vs 更弱"，而是"护城河建在哪一层"。
路线 A 认知外借最快落地但最易被替代；路线 D 统一一条式最有想象空间但最难验证；路线 B 与 C（小脑自研 / 双基模闭环）是当前证据链最强的两条路径——VPP2 与 DM0.5 分别给出了实证。置信度 中高
④ "VLA 还是世界模型"是个伪命题，真正的问题是"数据从哪来、由谁独占"。
架构已收敛为分层 + 融合，差异化回归到数据来源、数量与独占性。Figure 的付费众包、智元的 100× 数据扩张、银河通用的仿真合成，本质是三种数据成本曲线的竞争。置信度 高
⑤ 未来 12 个月的决定性事件：RoboDojo 类统一榜单的扩散，与通用基座厂商是否做本体。
前者决定"自研能力"能否被外部验证（进而决定估值），后者决定认知层被压缩的速度。两者都会让"说不出自己护城河在哪一层"的公司被快速重定价。置信度 中
